# Seedbank v1.1.6

Seedbank v1.1.6 fixes the no-local-Git GitHub publishing fallback for empty repositories.

## What changed

- Fixed the GitHub API upload fallback so newly-created empty repositories receive files through the GitHub Contents API.
- Avoided the Git database refs API for empty repositories, because GitHub does not allow creating refs in an empty repo through that endpoint.
- Added regression coverage proving the fallback uploads through `/contents/...` and does not attempt direct ref creation.
- Kept the existing local Git commit/push path as the preferred path whenever Git is available, preserving existing Linux/macOS behavior.

## Download

Download exactly one archive for your operating system:

- Linux: `seedbank-v1.1.6-linux-x64.tar.gz`
- macOS: `seedbank-v1.1.6-macos.tar.gz`
- Windows: `seedbank-v1.1.6-windows-x64.zip`

Each archive contains only the installer and runtime scripts needed for that operating system.

## Linux install

1. Download `seedbank-v1.1.6-linux-x64.tar.gz`.
2. Extract the archive.
3. Open a terminal in the extracted `seedbank-v1.1.6` folder.
4. Run:

   ```bash
   chmod +x Install-Seedbank.sh
   ./Install-Seedbank.sh
   ```

5. Wait for the installer to finish. It installs dependencies, builds Seedbank, installs the application launcher, starts the local Seedbank server/client, and opens Seedbank in your browser.
6. After install, launch Seedbank from your application menu.

To update an existing Linux install, extract the new archive and run `./Install-Seedbank.sh` again from the new folder. The launcher restarts the local runtime before opening Seedbank.

## macOS install

1. Download `seedbank-v1.1.6-macos.tar.gz`.
2. Extract the archive.
3. Open the extracted `seedbank-v1.1.6` folder.
4. Double-click `Install-Seedbank.command`.
5. If macOS blocks the installer because it was downloaded from the internet, right-click `Install-Seedbank.command`, choose **Open**, then confirm.
6. Wait for the installer to finish. It installs dependencies, builds Seedbank, installs `Seedbank.app` in your user Applications folder, starts the local Seedbank server/client, and opens Seedbank in your browser.
7. After install, launch Seedbank from Applications, Spotlight, Launchpad, or the Dock.

If macOS still blocks the extracted app or installer, open Terminal in the extracted folder and run:

```bash
xattr -dr com.apple.quarantine .
./Install-Seedbank.command
```

To update an existing macOS install, extract the new archive and run `Install-Seedbank.command` again from the new folder.

## Windows install

1. Download `seedbank-v1.1.6-windows-x64.zip`.
2. Extract the zip file.
3. Open the extracted `seedbank-v1.1.6` folder.
4. Double-click `Install-Seedbank.bat`.
5. If Windows SmartScreen appears, choose **More info**, then **Run anyway**.
6. Wait for the installer to finish. It installs dependencies, builds Seedbank, installs the Start Menu shortcut, starts the local Seedbank server/client, and opens Seedbank in your browser.
7. After install, launch Seedbank from the Start Menu.

If Node.js is not already installed, the Windows installer tries to install it automatically through `winget` or a portable Node.js download.

GitHub publishing needs GitHub CLI (`gh`) authenticated on the same machine. Run `gh auth login`, then restart Seedbank from the Start Menu. Installing Git for Windows is still recommended for full local commit/push behavior, but Seedbank can publish small generated project folders through GitHub's API when local Git cannot be found.

To update an existing Windows install, extract the new zip and run `Install-Seedbank.bat` again from the new folder. The Start Menu shortcut is replaced and the launcher restarts the local runtime before opening Seedbank.

## Logs and troubleshooting

- Linux/macOS launcher logs: `~/.cache/seedbank/seedbank.log`
- macOS app-wrapper logs: `~/Library/Logs/Seedbank/launcher.log`
- Windows launcher logs: `%APPDATA%\seedbank\seedbank.log`

Seedbank is a local web app. It runs a local API server and a local web client, then opens your normal browser to the local app.
