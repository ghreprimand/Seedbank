# Seedbank v1.0.1

Seedbank v1.0.1 fixes macOS app launching from Finder/Dock after a successful install.

## What Changed Since v1.0.0

- Fixed the generated `~/Applications/Seedbank.app` launcher on macOS.
- The app launcher now sets a macOS-friendly PATH before starting Seedbank, including Homebrew locations such as `/opt/homebrew/bin` and `/usr/local/bin`.
- Finder/Dock launch output now goes to `~/Library/Logs/Seedbank/launcher.log` so future macOS launcher issues are easier to diagnose.

## Download The Right File

Choose one file for your operating system:

- Linux: `seedbank-v1.0.1-linux-x64.tar.gz`
- macOS: `seedbank-v1.0.1-macos.tar.gz`
- Windows: `seedbank-v1.0.1-windows-x64.zip`

## Windows Install

1. Download `seedbank-v1.0.1-windows-x64.zip`.
2. Right-click the downloaded zip file and choose **Extract All...**.
3. Open the extracted `seedbank-v1.0.1` folder.
4. Double-click `Install-Seedbank.bat`.
5. If Windows asks whether to allow the script to run, allow it.
6. The installer checks for Node.js and npm. If they are missing, it tries to install Node.js automatically.
7. Wait while dependencies install and Seedbank prepares its runtime.
8. The installer creates a Start Menu shortcut named **Seedbank**.
9. Seedbank opens in your default browser at `http://127.0.0.1:5173`.

After install, start Seedbank from the Windows Start Menu by searching for **Seedbank**.

To stop Seedbank manually, open PowerShell in the extracted Seedbank folder and run:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\seedbank.ps1 stop
```

## macOS Install

1. Download `seedbank-v1.0.1-macos.tar.gz`.
2. Double-click the downloaded archive to extract it.
3. Open the extracted `seedbank-v1.0.1` folder.
4. Double-click `Install-Seedbank.command`.
5. If macOS asks for permission to run it, allow it.
6. The installer checks for Node.js and npm. If Homebrew is installed, it can use Homebrew to install Node.js.
7. Wait while dependencies install and Seedbank prepares its runtime.
8. The installer creates `Seedbank.app` in your `~/Applications` folder.
9. Seedbank opens in your default browser at `http://localhost:5173`.

After install, start Seedbank from `~/Applications/Seedbank.app`.

If macOS blocks the unsigned archive or app, open Terminal inside the extracted folder and run:

```bash
xattr -rc .
```

Then run `Install-Seedbank.command` again.

If the macOS app launcher still does not open Seedbank, check:

```text
~/Library/Logs/Seedbank/launcher.log
```

## Linux Install

1. Download `seedbank-v1.0.1-linux-x64.tar.gz`.
2. Extract the archive with your file manager, or run:

```bash
tar -xzf seedbank-v1.0.1-linux-x64.tar.gz
```

3. Open a terminal in the extracted `seedbank-v1.0.1` folder.
4. Run:

```bash
bash Install-Seedbank.sh
```

5. The installer checks for Node.js and npm. On common distributions, it can offer to install them with the system package manager.
6. Wait while dependencies install and Seedbank prepares its runtime.
7. The installer creates an application launcher entry named **Seedbank**.
8. Seedbank opens in your default browser at `http://localhost:5173`.

After install, start Seedbank from your application launcher.

To stop Seedbank manually, open a terminal in the extracted Seedbank folder and run:

```bash
bash scripts/seedbank stop
```

## First Run

On first launch, Seedbank shows a setup prompt.

1. Choose a project root folder. This is where Seedbank creates project folders when you graduate ideas.
2. Use **Browse** to choose a folder, or type/paste a path.
3. Use **Create** in the folder browser if you want to make a new folder.
4. Click **Save** to save the project root without leaving setup.
5. Use the AI assistance and GitHub publishing links if you want to configure those features now.
6. You can skip onboarding and return to it later from Settings → General.

## Notes

- Seedbank stores your ideas locally on your computer.
- Cloud AI providers are used only if you configure them.
- GitHub publishing is optional and uses your local `gh` CLI session. Seedbank does not store GitHub tokens.
- These archives are unsigned. Windows and macOS may show normal warnings for unsigned scripts.
